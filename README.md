# 📝 To-Do List CLI App (Python)

A simple and efficient command-line To-Do List application built using Python. This project helps users manage their daily tasks with basic CRUD operations (Create, Read, Update, Delete).

---

## 🚀 Features

* ✅ Add new tasks
* 📋 View all tasks
* ❌ Delete tasks
* ✏️ Mark tasks as completed
* 💾 Data stored locally (file handling)
* 🖥️ Simple CLI interface

---

## 🛠️ Technologies Used

* Python 3
* File Handling (Text/JSON)

---

## 📂 Project Structure

```
todo-list/
│
├── todo.py          # Main application file
├── tasks.txt        # Stores tasks

```

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/BM804/abc
```

2. Navigate to the project folder:

```
cd todo-list
```

3. Run the application:

```
python todo.py
```

---

## 💡 How It Works

* User selects options from the menu
* Tasks are stored in a file (`tasks.txt`)
* Each task can be added, removed, or marked as done
